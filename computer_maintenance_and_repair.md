### Question 1

**a) Define the term Computer Maintenance and Repair, then explain how an operating system is related to Computer Maintenance and repair?**

**Definition:**

**Computer Maintenance and Repair** is the practice of keeping computers in good working order, and performing corrective procedures when they fail. **Maintenance** involves proactive tasks such as cleaning, updating software, and scanning for malware to prevent problems from occurring. **Repair** involves reactive tasks such as diagnosing and replacing faulty hardware, or removing a virus.

**Relationship with the Operating System:**

The operating system (OS) is the core software that manages all of the hardware and software on a computer. It is therefore central to computer maintenance and repair in the following ways:

*   **Software Maintenance:** The OS is the platform on which all other software runs. Keeping the OS updated with the latest patches and security updates is a critical maintenance task.
*   **Troubleshooting:** The OS provides tools and utilities that can be used to diagnose and troubleshoot problems, such as the Device Manager, Task Manager, and Event Viewer.
*   **Hardware Management:** The OS manages the interaction between the hardware and software. If a hardware component is not working correctly, the OS will often be the first place to look for an error message or a clue to the problem.
*   **System Corruption:** If the OS becomes corrupted, it can cause a wide range of problems, from slow performance to a complete system failure. In this case, the OS itself may need to be repaired or reinstalled.

**b) There are various methods of installing an Operating System, which methods depend on the system hardware. You are required to write down and explain the four operating system installation methods.**

1.  **Attended Installation:** This is the most common method of installing an OS. It involves manually booting the computer from an installation media (such as a DVD or USB drive) and following the on-screen prompts to complete the installation.

2.  **Unattended Installation:** This method allows you to install an OS on multiple computers without having to manually attend to each one. It uses a script or an answer file to automate the installation process.

3.  **Network Installation:** This method allows you to install an OS on a computer over a network. The installation files are stored on a server, and the client computer boots from a special boot disk that connects to the server and starts the installation.

4.  **Image-based Installation:** This method involves creating a master image of an OS installation that can be deployed to multiple computers. This is a fast and efficient way to install an OS on a large number of computers.

### Question 2

**a) Describe the electrical specifications of the laptop's power adapter, explaining what each parameter means and what it does?**

A laptop's power adapter has several electrical specifications, which are typically printed on the adapter itself. These specifications include:

*   **Input Voltage:** The voltage that the adapter is designed to receive from the wall outlet. This is typically a range, such as 100-240V, to allow the adapter to be used in different countries.
*   **Input Frequency:** The frequency of the AC power that the adapter is designed to receive. This is typically 50-60Hz.
*   **Output Voltage:** The DC voltage that the adapter provides to the laptop. This must match the voltage required by the laptop.
*   **Output Current:** The maximum current that the adapter can provide to the laptop, measured in amperes (A) or milliamps (mA).
*   **Output Power:** The total power that the adapter can provide to the laptop, measured in watts (W). This is calculated by multiplying the output voltage by the output current.

**b) Differentiate between alternating current (ac) and direct current (dc).**

| Feature | Alternating Current (AC) | Direct Current (DC) |
| :--- | :--- | :--- |
| **Direction of Flow** | The direction of the current reverses periodically. | The direction of the current is constant. |
| **Source** | Power plants, wall outlets | Batteries, power supplies |
| **Use** | Powering homes and businesses | Powering electronic devices |

**c) A Desktop power supply changes alternating current from the mains outlet to direct current which it feeds to the computer components, so describe the 4 steps undertaken by a power supply to change ac voltage to dc voltage**

1.  **Transformation:** The AC voltage from the wall outlet is stepped down to a lower voltage by a transformer.
2.  **Rectification:** The AC voltage is converted to DC voltage by a rectifier.
3.  **Filtering:** The DC voltage is smoothed out by a filter to remove any remaining AC ripple.
4.  **Regulation:** The DC voltage is regulated to ensure that it remains constant, even if the load on the power supply changes.

**d) You witness a person who has been shocked by electricity and is lying on the ground near an electrical source. Write down seven (7) immediate actions you should take to provide first aid for electric shock?**

1.  **Don't touch the person:** If they are still in contact with the electrical source, you could be shocked as well.
2.  **Turn off the power source:** If possible, turn off the power at the circuit breaker or fuse box.
3.  **Move the source away from the person:** If you can't turn off the power, use a non-conducting object, such as a wooden pole or a dry rope, to move the electrical source away from the person.
4.  **Check for breathing and a pulse:** If the person is not breathing or has no pulse, begin CPR immediately.
5.  **Call for emergency medical help:** Call your local emergency number immediately.
6.  **Treat for shock:** If the person is conscious, lay them down with their head slightly lower than the rest of their body and their feet elevated. Cover them with a blanket to keep them warm.
7.  **Don't move the person:** If the person has fallen, they may have a spinal injury. Don't move them unless they are in immediate danger.

**(a) Explain the technical Boot process of the computer explaining clearly the different stages this process takes.**

The boot process is the sequence of events that occurs when a computer is first turned on. It is responsible for loading the operating system into memory and preparing the computer for use. The boot process can be divided into the following stages:

1.  **Power-On Self-Test (POST):** When the computer is first turned on, the BIOS/UEFI firmware performs a series of tests to check that the hardware is working correctly.
2.  **Bootloader:** The BIOS/UEFI then locates and loads the bootloader, which is a small program that is responsible for loading the operating system.
3.  **Operating System Kernel:** The bootloader loads the operating system kernel into memory. The kernel is the core of the operating system and is responsible for managing the computer's resources.
4.  **System Initialization:** The kernel then initializes the rest of the operating system, including the user interface and device drivers.

**(b) A number of facts can compromise or corrupt an operating system Write down and explain five (5) indicators which suggest that an operating system may be corrupt or compromised**

3.  **Strange Error Messages:** You may see strange or unusual error messages that you have never seen before.
4.  **Unwanted Pop-ups:** You may see a large number of unwanted pop-up ads, even when you are not browsing the internet.
5.  **Changes to Your Browser:** Your web browser's home page or search engine may have been changed without your permission.

**(c) Windows Operating System comes with several built-in system tools that can be used to repair or restore a corrupted operating system write down and explain at least five (5) inbuilt System tools.**
